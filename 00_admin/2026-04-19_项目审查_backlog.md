## Part 1 — 对项目的理解（先确认这里说的对，否则后面建议都无效）

### 1.1 项目灵魂

DMSD 有 **三重身份**，三层不冲突但强度不一：

| 身份 | 强度 | 对应文件集 |
|---|---|---|
| ① 真实要解决的宿舍点呼痛点 | 强（真诚） | spec / TODO / decision_log |
| ② itsuki 的技术成长轨迹 | 强（记录完整） | learning_path / project_evolution / dev_log |
| ③ AC 入試的叙事材料载体 | 中（散在各处，未整合） | raw/*#AC候选 / iCloud AC 目录 / memory |

**核心原创**：**语音播报防作弊**（4-12 提出）—— 不是学来的 pattern，是从"同学帮刷卡"的现实观察推导出的"技术 + 人防"组合。AC 面试时教授最想听的"你自己想出来的是什么"。

**核心认知突破**：**thin client / thick server**（4-15 提出）—— itsuki 主动反驳 AI 过度配置的结果。AC 面试时教授想看的"你不盲从 AI"的证据。

**五个核心问题的 coverage 现状**：

| # | 问题 | 覆盖度 | 证据位置 |
|---|---|---|---|
| #1 | 問題発見 / 为什么做 DMSD | 🟡 骨架在 | `project_evolution.md §起点` 仍有【】 |
| #2 | 問題意識 / 遇到了什么困难 | 🟢 充分 | problem_solving 4 篇 + 4-10 回归日 |
| #3 | 問題解決 / 怎么解决 | 🟢 充分 | decision_log 7 条 + spec v0.3.0 |
| #4 | 自己認識 / 学到了什么 | 🟡 散，未汇总 | learning_path + dev_log 4-10 三层反思 |
| #5 | 志望動機 / 为什么筑波 | 🔴 **几乎空白** | 无 repo 内文件，iCloud 里可能有 |

→ **最大缺口：#5 志望動機**。spec 再精密、学习再完整，志望动机说不清楚 AC 面试整块塌。

### 1.2 已经做对的事（先表扬，避免无意义动刀）

1. **CHANGELOG 细粒度**（pre-0.1 追认 6 条 + 2-02 至今每节点一条）
2. **CHANGELOG 每条 minor bump 写明"为什么升 minor"** —— 超出 Keep a Changelog 要求
3. **v0.1.1 主动 revert**（原标 v0.2.0 被自我审查降回 patch）—— AC 叙事加分
4. **字典四件套（ENUM / FIELD / ERROR_CODES / DEVICE_REGISTRY）的单源真值**
5. **防 AI 顺从性** —— memory + 4-15 主动反驳 AI 过度配置
6. **thin client / thick server 原则主动提出** —— 非教科书复读
7. **2025-12 → 2026-04 完整认知链路可追溯**
8. **学习路径 "为什么学 X 不学 Y"** —— 选型有理由

### 1.3 AC 提交时的 reader's journey 预测

假设 AC 教授收到 GitHub 链接后会按这个顺序翻：

```
GitHub 首页 (README.md)   →  一句话没看到"DMSD 是什么"
    ↓
目录结构 / commit log     →  看到 "v0.3.0: spec main body rewrite" / "AC 素材移 iCloud"
    ↓
CHANGELOG.md              →  看到完整版本链（好）
    ↓
最关心的业务 / spec       →  RollCall_Spec.md（958 行，可读，但长）
    ↓
"作者怎么想的"证据         →  decision_log / project_evolution → 发现停在 4-13（空 6 天）
```

**当前最大的 AC 风险**：
- 教授进 repo **第一眼看空白**（没 README）
- 看 commit log **看到 AC 素材暴露**（"AC 素材移 iCloud"commit 很显眼）
- 看 decision_log / project_evolution **看到停在 4-13**（过期 6 天）
- 看 learning_path **看到 "即将学 Python Day 2"**（39 天没动）

**结论：现在的 repo 不 AC-ready**。内容质量高，但"外观一致性"差。
