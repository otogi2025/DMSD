## 三、铁律（DMSD 项目通用，违反会出事）

- **不 push / 不打 tag 到远程 / 不删 tag**，除非 itsuki 当场明确说。本地 commit 可自主。
- commit 不写 `Co-Authored-By` trailer。
- **多会话共用同一个 git 暂存区**：commit 前必须 `git diff --cached` 逐项核对，只 commit 自己改的，用显式文件路径 `git add <具体文件>`，**绝不 `git add -A`**（会带走别会话预先 stage 的改动）。
- 中文回答 itsuki；英文/日语/缩写第一次出现要翻译 + 一句解释（他编程零基础）。
- 破坏性命令（`git reset --hard` / `rm`）先跟 itsuki 确认。
