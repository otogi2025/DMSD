# handoff — AI 会话间交接文件夹

> 2026-06-05 itsuki 拍板建立。专门放**正在生效**的「一个 Claude Code 会话写给另一个会话」的交接文件 —— GOAL 提示词 / 接手提示词 / 压缩点上下文交接 等。

## 为什么单独建这个文件夹

交接文件是**用完即弃的一次性东西**。以前散着丢在 `00_admin/` 根目录（治理台账区）+ `05_logs/`，没人负责删，越堆越多。`00_admin/` 根目录是放**项目从头活到尾的长期治理台账**的（WIP.md / TODO.md / 项目心智模型.md / 文档同步点清单.md / progress_overview.md / 系统bug专栏.md / hooks），不该混进一次性交接件。

## 规则（铁律）

1. **只放活的交接文件** —— 还没被接手完成的。
2. **接手的会话任务做完后，最后一步**把对应交接文件**移到 `99_archive/YYYY-MM-DD_handoff已完成/`**（留痕不删 —— 将来写 AC 入试叙事时，这些是「多会话协作工程」的证据）。
3. **不放这里的**：长期治理台账（WIP/TODO/心智模型/同步点清单等）留在 `00_admin/` 根；开发日志 / AC 素材留在 `05_logs/`。
4. 这条规则同时写进 [[session-wrap]] skill 收尾流程，靠机制清理、不靠自觉。

## 命名

- `<任务名>_交接_YYYY-MM-DD.md`（一次性接手提示词）
- `<任务名>_GOAL提示词.md`（驱动一个大任务的 /goal 提示词，任务期间长期有效，完成后归档）
