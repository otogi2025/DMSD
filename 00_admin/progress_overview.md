## 核心功能：点呼系统

### 流程
1. 老师在管理端点击"开始点呼"
2. 学生在手机上碰 NFC 标签签到
3. 系统自动判定：准时 / 迟到 / 缺席
4. 老师可以手动改判（需填写理由，系统留审计记录）
5. 到时间未结束 → 系统自动结束并结算

### 纪律规则
- 迟到：+0.5 分
- 缺席：+1.0 分
- 月累计 ≥ 4.0 → 下月罚扫
- 月累计 ≥ 9.0 → 下月禁足

## 问题解决记录

| 问题 | 怎么解决的 | 学到了什么 |
|------|-----------|-----------|
| tar 打包报错 "no files or directories specified" | -C 只切换目录，后面还要跟目录名 | 命令参数各有各的作用，不能省略 |
| scp 传文件没反应 | 缺少目标路径 `:/root/`，scp 需要完整的 `user@ip:path` | 远程命令格式要写完整 |
| Python 报错 NameError | 变量要先创建（赋值）再使用，代码从上往下执行 | 编程语言的执行顺序很重要 |
| Python 布尔值 true 报错 | Python 要求大写 True/False | 每种语言有自己的语法规定 |
