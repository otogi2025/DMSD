# DMSD v0.1 冻结决策（当前唯一真值）

更新时间：2026-02-12

## 1. 纪律阈值（已固定）
- 迟到：`0.5` 分
- 缺席：`1.0` 分
- 月累计 `>= 4.0`：下月罚扫
- 月累计 `>= 9.0`：下月禁足

## 2. 点呼场次状态（已统一）
- `session_status = draft | running | ended`

说明：
- 现阶段不引入 `cancelled` / `archived`。
- 需要取消场次时，按运营流程处理并记录审计日志，后续版本再扩展状态枚举。

## 3. 规则优先级（按 RollCall_Spec）
- 以 `RollCall_Spec_v0.1` 为准。
- 全流程状态机文档已移除，当前不作为实现依据。

## 4. 座位显示原则（按 RollCall_Spec）
- 主色状态：灰（初始）/绿（准时）/黄（迟到）/红（缺席）
- 特殊状态：
  - 红十字：健康异常（叠加图标）
  - 免：免点呼（叠加标记）
  - 申：本场不点呼申请中（叠加标记，需老师处理）

## 5. 实施要求
- 前端、后端、测试样例都必须引用本文件中的阈值与枚举。
- 如有变更，先改本文件，再改 API 契约与代码。
