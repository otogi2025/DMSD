# monthly_review — 月度回顾

> 每月最后一周,固定花 1 小时做。
> 从这个月的所有记录里筛选 3-5 条最有故事性的事件,标记为 AC 候选素材。

## 为什么需要这个

日记式记录的问题是记了就忘。到 7 月写自我推荐书时,如果要从 80 篇 dev_log 里翻找素材,会崩溃。月度回顾相当于每月做一次素材筛选,7 月直接用筛选好的就行。

## 文件名格式

`YYYY-MM.md`

例:
- `2026-04.md`
- `2026-05.md`

## 格式模板

```markdown
# YYYY-MM 回顾

## 这个月的工作总览
(浏览所有 dev_log 后的概括,200 字以内)

## 这个月的 3-5 条 AC 候选素材
1. [日期] [事件] - 为什么值得放进自我推荐书
2. ...

## 这个月对核心主题的新认识
(我对自己在做什么、为什么做、做的方向有没有新看法?)

## 下个月想做的事
1. ...

## 下个月想避免的坑
(这个月犯了什么错,下个月不要再犯)
```
