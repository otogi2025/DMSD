# iPhone 快捷指令配置: NFC 卡触发 Web 打卡

## 目标

把一张 NFC 卡贴在手机上时, iPhone 自动发一个 HTTP 请求到 Mac 上的 Flask 服务器, 触发座位变绿 + 语音播报。

## 前置条件

- [ ] Mac 和 iPhone 在同一个 WiFi
- [ ] Mac 上的 Flask 服务器已启动 (运行过 `./run.sh`)
- [ ] 已经在 Mac 终端查到局域网 IP (`ifconfig | grep "inet " | grep -v 127.0.0.1`)
- [ ] 已经把 `frontend/script.js` 里的 `MAC_IP` 改成那个 IP
- [ ] 手上有一张 NFC 卡 (任何 NTAG215、公交卡、银行卡、学生证都可以, 只要 iPhone 能识别)
- [ ] iPhone 是 iPhone XS 或更新 (需要支持后台 NFC 读取 / 自动化)

## 步骤

### 第一步: 查 Mac 的局域网 IP

打开 Mac 的"终端"App, 输入:

```
ifconfig | grep "inet " | grep -v 127.0.0.1
```

你会看到类似这样的输出:

```
inet 192.168.1.5 netmask 0xffffff00 broadcast 192.168.1.255
```

那个 `192.168.1.5` 就是你要的 IP 地址。**记下来。**

> 如果看到多行, 一般第一个 `192.168.x.x` 或 `10.x.x.x` 开头的就是 WiFi 网卡的 IP。

### 第二步: 打开 iPhone 的"快捷指令" App

iPhone 自带这个 App, 图标是紫色/蓝色的, 两个叠在一起的图形。如果桌面找不到, 向下滑屏幕搜索"快捷指令"或"Shortcuts"。

### 第三步: 创建"获取 URL 内容"快捷指令

1. 在"快捷指令" App 里, 点底部的"快捷指令"标签
2. 点右上角的 "+" 号 (加号) 新建一个快捷指令
3. 顶部输入快捷指令名字: 比如 "打卡 S001"
4. 点中间大大的"添加操作"按钮 (或搜索栏)
5. 在搜索框里输入 "URL"
6. 找到并点击 "获取 URL 内容" (Get Contents of URL)
7. 现在看到一个带 "URL" 字样的方块。点那个 URL 字段
8. 输入完整的 URL: `http://192.168.1.5:8000/checkin?student_id=S001` (把 192.168.1.5 换成你的 Mac IP)
9. 点 URL 方块下面的"显示更多" (Show More) 展开更多选项
10. 把"方法"从 GET 改成 **POST**
11. 点右上角"完成"

### 第四步: 测试这个快捷指令

回到"快捷指令"列表, 点你刚创建的"打卡 S001"。应该会在 Mac 浏览器看到 101-A 座位变绿 + 听到"欢迎 itsuki"。

如果没反应, 看"故障排查"部分。

### 第五步: 把快捷指令绑定 NFC 卡

1. 打开"快捷指令" App, 切到底部的 **"自动化"** 标签 (Automation)
2. 点右上角 "+"
3. 选 "创建个人自动化" (Create Personal Automation)
4. 在列表往下滑, 找到 **"NFC"**, 点它
5. 点"扫描", 把 NFC 卡贴到 iPhone 顶部 (iPhone 的 NFC 在屏幕上方)
6. 识别成功后给这张卡起个名字, 点"下一步"
7. 在"操作"页面, 点"添加操作"
8. 搜索"运行快捷指令" (Run Shortcut), 选它
9. 点那个操作, 选择"打卡 S001" (你之前创建的)
10. 点"下一步"
11. **重要**: 把"运行前询问" (Ask Before Running) 关掉, 这样碰卡时不用手动确认
12. 点"完成"

### 第六步: 实战测试

- 确保 Mac Flask 服务器还在运行, 浏览器打开前端页面
- iPhone 解锁状态下, 把 NFC 卡贴到 iPhone 顶部
- 应该几秒内看到座位变绿 + 听到播报

## 故障排查

**问题: 测试快捷指令时报"无法连接"**

- 检查 Mac 和 iPhone 是否在同一 WiFi
- 检查 Mac 的 Flask 服务器是否还在跑
- 检查 URL 里 IP 是否正确
- 尝试: 手动在 Mac 浏览器打开 `http://<你的IP>:8000/events`, 如果也打不开, 就是防火墙/WiFi 隔离问题。Mac 系统设置 → 网络 → 防火墙, 临时关闭试试

**问题: iPhone 碰卡没任何反应**

- 确保卡贴在 iPhone 顶部 (不是中间或下面), 稍微靠近听筒位置
- iPhone 必须解锁, 屏幕亮着
- 检查"自动化"里你创建的那条是不是处于开启状态
- 换张卡试试 (有些卡加密了或损坏)

**问题: 学校/公司 WiFi 不让设备互通**

- 解决方案: iPhone 开个人热点 → Mac 连 iPhone 热点 → 重新查 Mac IP (会变) → 更新 script.js → 重启服务器

**问题: 想让同一张卡触发不同快捷指令**

- iPhone 自动化里, 一张 NFC 卡只能绑一个自动化
- 如果要演示多个学生, 准备多张卡, 每张绑不同的"打卡 SXXX"快捷指令
