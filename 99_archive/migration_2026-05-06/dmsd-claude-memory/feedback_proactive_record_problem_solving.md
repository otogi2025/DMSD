CC 看到 itsuki 不知道的问题（技术 / 流程 / AC / 学习方法 / 自我管理）→ **不仅要当场跟他说**（§对话规则 §7「主动诊断 unknown unknowns」），**还要主动 dump 到 raw/** 当成他的 AC 素材。

**Why**: itsuki 2026-05-04 原话：

> 「我最主要的还是需要你的辅助，**有时候我不会自己去记录包括我发现问题、解决问题的能力**。**有时候并不是我发现问题，是你发现了问题，但是也算到我的头上**」

- itsuki 是高中生，没系统学过自我反思框架
- 解决问题的过程他不会主动记下来（即使是他做的）
- CC 发现的问题，他做了"采纳 / 拒绝 / 修改"判断 = 他的判断也是 AC 素材
- 不主动 dump = 他损失 AC 素材（他不会自己回忆然后写下来）

**How to apply**:

- 看到 unknown unknown → 当场说 + **同会话内主动 dump raw/**（不等会话结束）
- itsuki 反应（接受 / 拒绝 / 修改）→ 都记，包括"他为什么拒绝"
- dump 时按 §AC 记录协作 §⭐ 根本性原则 §1 — 写"我（itsuki）发现 / 我决定"，不写"CC 发现 / CC 推荐"
- 触发时机 = §对话规则 §7「主动诊断」+ 本规则「主动记录」 = **一对组合，缺一不可**

**正例**:

- ✅ "今天 CC 提醒我 GitHub public 后 git log 永久保留所有改动 → 我意识到自动 push 风险大 → 拒绝授权 → 改成 commit 自动 / push 等明示" — dump 这个，写"我意识到 / 我拒绝 / 我改成"
- ✅ "今天 CC 发现我把 commit 和 tag 概念混淆了 → 我接受了澄清 + 接受了 CC 推荐的分工" — dump，写"我学到了两个工具的差别 + 我接受了新分工"
- ✅ "今天 CC 指出 WIP 和 TODO 重叠 218 行 → 我拍板方案 A 砍重复" — dump，写"我注意到流程问题 + 我拍板"

**反例**:

- ❌ "CC 推荐 X，我说 OK" — 不写 raw（无判断痕迹，看不出 itsuki 的角色）
- ❌ "CC 发现 bug，CC 修了" — 不算他的 AC 素材（没有他的判断点）
- ❌ "CC 心里想了很多 unknown unknowns 但没说出来" — 直接违反 §对话规则 §7

**关联**:

- 这条是 §对话规则 §7「主动诊断 unknown unknowns」的延伸 — 主动诊断 + 主动记录 = 一对组合
- 也是 §AC 记录协作 §⭐ 根本性原则 §1「CC 决定 + CC 动作 = itsuki 做的」的具体执行手法
- 也跟 §⭐ 根本性原则 §2「没有素材就硬凹」呼应 — 即使是 CC 发现的小问题，也是 itsuki 的"判断力练习"素材
