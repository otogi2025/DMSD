### 4. 不假设他记得我们之前定的代号

即使 4-29 一起拍板的 R1-R4,4-30 重新讲一次。**会话间没有连续记忆假设**。

### 5. 大白话优先,术语后置

错: "#21 老龄 R2 一本道 UX"

### 6. 文档同样适用

### 7. 主动加术语小词典

任何长文档(spec / baseline / plan)如果用了 5+ 项目内部代号 / 日语词 / 英文缩写,**结尾加一节"术语小词典"**给 itsuki 复习用。
