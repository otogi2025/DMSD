给选项时**只用 A / B / C / D / E**，不要用：

- ❌ 甲 / 乙 / 丙 / 丁（中文天干）
- ❌ α / β / γ / δ（希腊字母）
- ❌ 一 / 二 / 三（中文数字）
- ❌ ①②③（带圈数字）

**Why:**
- 甲乙丙：2026-04 初明确要求过"以后不要再给我什么甲乙之类的了，用英文字母"
- 希腊字母（2026-04-20 新加）：itsuki 原话"你给我方案名字不要给这种符号，就普通 ABC 就可以了"。触发点 = CC 今天在议题 A 里用了 α / β / γ / δ 命名四种缓解方案
- 根因：itsuki 是零基础 + 中日双语母语，希腊字母和天干都不是他日常自然阅读的符号，读起来有额外认知负担

**How to apply:** 任何需要列选项让他选的场合，一律用 A / B / C / D / E。选项多时继续 F / G / H。连 sub-option 也一样（不是"A.α / A.β"，而是 "A-1 / A-2"）。
