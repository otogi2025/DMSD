# interview_log — 访谈记录

> 和他人讨论项目、做用户访谈、收集反馈时写。
> AC 入试评委特别看重"你的项目是不是只是自嗨"。

## 什么时候写

- 和同宿舍同学讨论过项目
- 宿舍管理老师给了反馈
- 学校电脑老师看了方案
- 家人/朋友问了你一个让你重新思考的问题

## 文件名格式

`YYYY-MM-DD_对方身份.md`

例:
- `2026-05-15_同宿舍同学.md`
- `2026-06-03_宿管老师.md`
- `2026-06-20_电脑老师田中先生.md`

## 格式模板

```markdown
## YYYY-MM-DD — 与 [谁] 的讨论

**对象**: (姓名/身份/和项目的关系)
**时长**: 约 X 分钟
**场景**: (在哪里、什么契机)

## 我说了什么
(我怎么介绍/演示项目的)

## 对方的反应

## 对方提出的问题/反馈
1. ...
2. ...

## 我之前没想到的点
(对方说了什么是你没考虑过的)

## 由此产生的行动
- [ ] ...
```
