## 本文（変更しない形で保管）

学校休業日等に、寮生やボランティア等に取り組む通学生は、特別運航便(無料スクールバス)に乗車して構いません。寮生は乗車名簿に事前にチェックをつけて下さい。バス乗車時は、挨拶等の礼儀作法に気をつけてください。また引き続き、感染症対策(手洗い・うがい・消毒等)に努めて下さい。

＊集中して学習やスポーツに取り組む時間と自由なオフタイムのメリハリをつけ、節約しながら休日は思いっ切りリフレッシュしてほしいので、特別運航便を案内しますが、技師(運転士)から悪い報告を受けた場合は該当者の乗車を一定期間拒否することがあり得ます。

＊乗車簿を寮監が確認後、多すぎる場合は乗車便調整を行う場合があります。

＊長期間の帰省・一時帰国等のタイミングは、情勢変化によって変更があり得ます。次回ゴールデンウィーク時10日間ほど休みがありますが、夏休みに高3生以外は帰省・外泊・一時帰国をすることを推奨します。

## スキーマ導出（老师 Web バス表管理 UI の設計）

この通達から読み取れる entity:

```
bus_schedule_posts                     -- 告知全体（1 通達 = 1 post）
├── id                UUID PK
├── posted_on         DATE             -- 2026-03-22
├── posted_by         TEXT             -- 国際交流部・技師
├── title             TEXT             -- 特別運行便に関するお知らせ
├── body_markdown     TEXT             -- 前文（寮監確認 / 節約 / 帰省推奨 等）
├── effective_from    DATE             -- 2026-04
├── effective_until   DATE NULL        -- 情勢変化で変更可、NULL = 継続中
├── category          ENUM             -- '特別運行便' / '定期便' / 'イベント' 等
└── pinned            BOOLEAN

bus_events                             -- 告知に含まれる日付ごとのイベント
├── id                UUID PK
├── post_id           UUID FK → bus_schedule_posts.id
├── event_date        DATE             -- 2026-04-05
├── event_name        TEXT             -- 留4アクティビティ
├── audience          TEXT             -- 「4 月生及び 4 月生をサポートする意志...」
└── memo              TEXT

bus_schedule_items                     -- イベント内の時刻行
├── id                UUID PK
├── event_id          UUID FK → bus_events.id
├── time              TIME             -- 09:10
├── action            TEXT             -- 日本語プレイスメントテスト / 金川駅発（寮行き）等
├── location          TEXT NULL        -- 岡山城 / RSK / 河川敷 等
├── memo              TEXT NULL
└── order_index       INT              -- 並び順
```

**UI 要件**（老师 Web「バス時刻表 管理」）:
- Post 一覧（最新順 + ピン留め上部）
- Post 新規作成 / 編集 / 削除
- Post 内で Event を複数追加
- Event 内で 時刻行を drag & drop で並び替え
- プレビュー → 学生 App に push / 掲示板に掲載
- **学生側**: iOS App「バス」タブで今日/今週の関連イベントを表示（日付ベース filter）

- 原文には「2026年4月からリンク先変更注意」とあり、**旧システム（紙 / PDF / 既存掲示板）との移行が前提**
