# 点呼机接线说明（首台演示机）

> 本文档记录点呼机各模块接 Raspberry Pi 3A+（主板）的接线方法。
> **上游**：硬件选型见 `02_design/hardware_design.md`；点呼机软件层见 `ROLLCALL_DEVICE_DESIGN_LOG.md`。
> **状态**：⏳ 待硬件到货实测确认 —— LED 的 GPIO 分配来自 `hardware_design.md §2.4.1`；PN532 / ST25DV 的引脚标注以实物板子为准（淘宝 / Amazon 系模块批次有差异，到货后核对丝印再接）。

---

## 0. 名词先解释

| 名词 | 是什么 |
|---|---|
| GPIO | Pi 板边那一排 40 根金属针，全称「通用输入输出脚」，用来接各种模块 |
| 物理针号 | 板子上 40 根针的物理位置编号（1-40），数针时用这个 |
| BCM 编号 | 代码里写的脚编号（跟物理针号不一样，别搞混）|
| SPI | 一种芯片间高速通信总线，PN532 走这个 |
| I²C | 另一种芯片间通信总线（2 根线），ST25DV 走这个 |
| 共地 | 所有模块的「接地脚」都要连到 Pi 的接地针，电路才通 |

---

## 1. 接线总览

| 模块 | 接 Pi 方式 | 占用 |
|---|---|---|
| PN532 读卡器（路径 A）| SPI | SPI0 的 4 根针 + 电源 + 接地 |
| ST25DV 贴纸（路径 B）| I²C（焊排针 + 母-母杜邦线）| I²C 2 根针 + 电源 + 接地 + GPO 中断脚 |
| LED 状态灯 ×4 | GPIO（**5V 驱动 / 低电平点亮**）| 4 个 GPIO + 4 个 220Ω 接 5V 针 |
| 风扇 | 5V 直接供电 | 5V 针 + 接地（**不接信号脚**）|
| USB 喇叭 | USB | Pi 唯一的 USB 口 |

## 2. PN532 读卡器 — 走 SPI

为什么走 SPI 不走 I²C：ST25DV 已经占了 I²C 总线，两个设备挤一条 I²C 在 Pi 上容易出问题。PN532 在 Pi 上走 SPI 最稳（Codex + 第二个 AI 审查都确认）。

PN532 V3 红板要先用板上的拨码开关 / 跳线切到 SPI 模式（到货看说明书）。

| PN532 脚 | 接 Pi 的针 | 物理针号 | BCM 编号 |
|---|---|---|---|
| SCK | SCLK | pin 23 | GPIO11 |
| MISO | MISO | pin 21 | GPIO9 |
| MOSI | MOSI | pin 19 | GPIO10 |
| SS / NSS | CE0 | pin 24 | GPIO8 |
| VCC | **接 3.3V**（pin 1）—— 走 SPI 时模块是 3.3V TTL 逻辑（你商品页写明），VCC 也用 3.3V → 全程 3.3V，彻底无顶坏针脚风险（2026-06-04 Codex 复核）| pin 1 | — |
| GND | 接地 | pin 6 | — |

## 3. ST25DV 贴纸 — 走 I²C（焊排针版）

> 2026-06-04 改：原写「经 Qwiic 免焊线」已废 —— Qwiic 免焊套件 ¥3,090 太贵不买，改自己焊排针（PN532 反正也要焊，工具都有）。

板底 6 个焊孔焊上排针（2.54mm，排针套装里有），再用母-母杜邦线接到 Pi。

| ST25DV 脚 | 接 Pi 的针 | 物理针号 | BCM 编号 |
|---|---|---|---|
| SDA | SDA | pin 3 | GPIO2 |
| SCL | SCL | pin 5 | GPIO3 |
| VCC（3.3V）| 3.3V | pin 1 / pin 17 | — |
| GND | 接地 | pin 9 | — |
| GPO（中断 / 门铃脚）| 任一空闲 GPIO | 待定 | 待定 |

> ST25DV 比 PN532 多一根 GPO「门铃」线：手机写进邮箱时它把这根拉低通知主板。GPO 是开漏输出，**要接 1 个 10kΩ 电阻上拉到 3.3V**（外部上拉，2026-06-04 Codex 复核建议 —— 比只靠树莓派内部弱上拉稳，尤其线长 15-20cm + 在 NFC 场旁边）。代码里同时开内部上拉（PUD_UP）兜底。10kΩ 电阻已采购（秋月 125103）。

## 4. LED 状态灯 ×4（A 方案：5V 驱动 / 低电平点亮，2026-06-04 改）

> **为什么不接 3.3V GPIO 直驱**：绿 / 蓝 / 白 LED 工作电压（Vf）接近 3.1-3.2V（绿 OSPG5111A 查证秋月官方页 g112117 = 3.1V）。用 Pi 的 3.3V 信号针 + 220Ω 直驱，电流只有约 0.5-0.9mA，几乎不亮，连最重要的成功绿灯都点不亮。改成从 **5V 针**驱动、信号针当开关（低电平=亮），电流约 8.6mA，全亮。itsuki 2026-06-04 拍板走 A（不加三极管，零成本）。

**接法**：LED **长腿（正极）→ 串 1 个 220Ω 电阻 → 5V 针（pin 2 / pin 4）**；**短腿（负极）→ GPIO 信号针**。代码里那个 GPIO **输出低电平（0V）= 亮**，高电平（3.3V）= 灭（反逻辑，代码侧处理）。

| 颜色 | 含义 | 短腿接(GPIO) | 物理针号 | BCM 编号 |
|---|---|---|---|---|
| 蓝 | 待机 | GPIO22 | pin 15 | GPIO22 |
| 绿 | 签到成功 | GPIO27 | pin 13 | GPIO27 |
| 红 | 失败 | GPIO17 | pin 11 | GPIO17 |
| 白 | 启动中 | GPIO23 | pin 16 | GPIO23 |

4 个 LED 的长腿都经各自的 220Ω 电阻接到 5V 针（pin 2 或 pin 4）。

> **安全核对（2026-06-04 Codex 复核修正）**：点亮时（GPIO 输出低电平）信号针约 **0V**，在吸收 8.6mA —— 那 1.9V 是**电阻上的压降**，不是针脚电压（之前写「信号针 1.9V」是错的）。熄灭时（GPIO 输出高电平 3.3V）针脚被树莓派主动驱动到 3.3V，5V 被熄灭的 LED 挡在另一头、传不到针脚。所以针脚电压始终在 0~3.3V，不超上限，5V 顶不坏针脚；每针吸收 8.6mA < 16mA 单针上限，4 灯全亮约 39mA < 50mA 总上限。安全。红灯 Vf~2V 同接法约 13.6mA，可接受。
>
> **代码注意（反逻辑 + 开机）**：① 低电平=亮、高电平=灭，代码里封装好别写反；② 程序一启动第一件事就把 4 个 LED 的 GPIO 设成「输出高电平（灭）」，否则开机瞬间引脚浮空可能微亮。

## 5. 风扇 — 5V 直供

⚠️ **风扇绝对不能接 GPIO 信号脚**（信号脚最大输出约 16mA，风扇要 100mA 会烧坏 Pi）。

| 风扇线 | 接 Pi 针 | 物理针号 |
|---|---|---|
| 正极（红）| 5V | pin 2 或 pin 4 |
| 负极（黑）| 接地 | pin 6 / pin 9 / pin 14 等任一 |

你买的秋月 114184 风扇是 **2.54mm 2 针接头**，直接套到 pin 4(5V)+pin 6(GND)，**红线对 5V，别插反**。

## 6. 喇叭 — USB

Lazos L-SK-B USB 喇叭：**USB 口取电**（插 Pi 唯一的 USB 口）+ **3.5mm 音频线**插 Pi 的 3.5mm 音频口。Pi 用 `aplay` 播放后端预生成的日语语音 wav 文件。

> 装系统后要 `raspi-config` 把声音从 HDMI 切到「模拟音频」，否则 3.5mm 不出声。

调试期键盘鼠标没 USB 口插（被喇叭占了）→ 全程用 SSH 远程登录。

## 7. 接线注意事项（零基础避坑）

1. **断电接线** —— 接 / 拔任何线之前先拔 Pi 电源，带电插拔可能烧板
2. **物理针号 ≠ BCM 编号** —— 数针时用物理针号（板子角落 pin 1 开始数），代码里用 BCM 编号
3. **共地** —— 所有模块的接地脚都要连到 Pi 接地针，少接一个电路就不通
4. **先单独测每个模块** —— 别一次全接上。先接 PN532 测读卡 → 再接 ST25DV 测写贴纸 → 再接 LED → 最后风扇喇叭。一个一个来，坏了好排查
5. **Qwiic 线 / PN532 引脚到货核对丝印** —— 模块批次有差异，按实物板子上印的脚名接，不要盲信本表
