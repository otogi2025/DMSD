① 最终要达到的目的与效果

这台机器要解决什么

宿舍每晚点呼（查学生有没有按时回宿舍）原来靠舍监挨个房间敲门、纸上打钩，慢、易漏、没法防代答。点呼机把这件事数字化：

  • 学生端：晚上回宿舍，把学生卡贴一下读卡器，或用手机碰一下贴纸，1 秒完成签到。
  • 老师端：电脑/手机上实时看到谁回了、谁还没回，迟到 / 缺席自动判定、自动扣纪律分，不用手记。
  • 防代刷：卡有唯一编号（防随便复制）；手机碰一下直接把身份写进贴纸的邮箱，主板当场读出并盖时间戳上报（手机全程不联网，没有网址可截图转发）。最终靠老师听播报后对人脸（人眼确认）。
  • 现场反馈：签到成功亮绿灯 + 喇叭播日语姓名（「○○さん、お帰りなさい」=「○○同学，欢迎回来」），失败亮红灯。

对我（itsuki）来说还有一层目的：学习

这台机器不只是买来用，更是买来亲手组装、搞懂原理的学习材料：

  • 第一次拿烙铁焊接（焊排针）—— 零电子经验跨出第一步
  • 搞懂主板那排针脚（GPIO）怎么接模块
  • 搞懂两种芯片间通信方式 SPI 和 I²C 的区别
  • 搞懂 NFC（近场通信，手机/卡贴近就能读）怎么工作
  • 这些动手过程本身就是升学（AC 入試）要讲的素材

② 机器由什么组成、怎么工作

大脑：Raspberry Pi 3 Model A+

一块巴掌大的小电脑（树莓派），跑 Python 程序。它板边有一排 40 根金属针叫 GPIO（通用输入输出脚），用来接各种模块。

两条签到路径

路径 A — 刷学生卡：

学生卡（NTAG215）→ 读卡器（PN532）读出卡号 → 主板 Python → 网络发后端 → 后端判定签到 → 推送老师端

路径 B — 手机碰贴纸：

学生手机碰一下贴纸（ST25DV）→ 手机把身份数据写进贴纸的邮箱（Mailbox，芯片里一块手机和主板都能读写的内存）→ 贴纸的门铃针（GPO 中断）通知主板 → 主板用 I²C 读出邮箱数据 → 主板盖时间戳 → 网络发后端（手机全程不联网）

5 个模块各干什么

模块 是什么 / 干什么 怎么接主板
PN532 读卡器 读学生卡的唯一编号 SPI（一种高速 4 线通信总线）
ST25DV 贴纸 能被手机写入、又能被主板读的特殊 NFC 标签（带邮箱内存） I²C（一种 2 线通信总线）
LED 灯 ×4 绿成功 / 红失败 / 蓝待机 / 白启动 数字脚，每个串 1 个电阻
风扇 主板长时间跑会热，吹散热（必须 5V） 接 5V 供电针
喇叭 播日语姓名 音频插 3.5mm；USB 取电插单独充电头

软件怎么转

主程序是个循环（状态机）：待机 → 读到卡/手机碰 → 提交后端 → 成功亮绿/失败亮红 → 回到待机。

为什么 PN532 走 SPI 不走 I²C：ST25DV 已经占了 I²C 这条线，两个挤一条容易出问题；PN532 在树莓派上走 SPI 最稳（两个外部 AI 审查都确认）。

⑤ 接线速查（详见 点呼机接线说明.md）

PN532 → 主板（SPI）

SCK  → pin23 / GPIO11
MISO → pin21 / GPIO9
MOSI → pin19 / GPIO10
SS   → pin24 / GPIO8
VCC  → 3.3V 或 5V（看模块标）
GND  → pin6（接地）

红板先用拨码/跳线切到 SPI 模式

ST25DV → 主板（I²C，焊排针版）

SDA → pin3 / GPIO2
SCL → pin5 / GPIO3
VIN → 3.3V
GND → pin9（接地）

板底 6 个焊孔焊排针，再用母-母杜邦线接

LED ×4（每个串 220Ω · 5V 驱动 / 低电平点亮）

蓝 待机  → 短腿 pin15 / GPIO22
绿 成功  → 短腿 pin13 / GPIO27
红 失败  → 短腿 pin11 / GPIO17
白 启动  → 短腿 pin16 / GPIO23
4 个长腿 → 各串 220Ω → 5V（pin2 / pin4）

2026-06-04 改 A 方案：长腿(正极)→电阻→5V 针，短腿(负极)→GPIO 信号针；代码 低电平=亮。原「3.3V GPIO 直驱」会让绿/蓝/白几乎不亮（绿 Vf 3.1V，查证秋月官方页 g112117）。

风扇 / 喇叭

风扇正极 → 5V（pin4）／负极 → 接地（pin6）
风扇 2.54mm 接头直插 pin4+pin6，红线对 5V，别插反
喇叭 → 音频 3.5mm 插主板；USB 取电插单独充电头（不占主板 USB 口）

⚠️ 风扇绝不接 GPIO 信号针（会烧主板）；风扇必须 5V

接线 7 条避坑：① 接线前先拔电源　② 物理针号 ≠ 代码里的 GPIO 编号　③ 所有模块接地连一起　④ 先单独测每个模块别一次全接　⑤ 到货按板子上印的脚名接　⑥ LED 必串电阻　⑦ 风扇只接 5V
