## 19:45 [技术判断 / 模式 6] 11 配件能组装论证 + 3 个真坑识别

### 背景 / 触发

CC 上网查证完毕,需要给 itsuki 一份**诚实**的报告 — 不是"全部 OK 你可以买",也不是"有问题别买"。

### 经过

CC 把 11 配件分 5 个层次报告:
1. 每个配件干嘛(角色对照表) + 是否 OK
2. 接口能不能对得上(物理 + 电气)
3. 3 个真坑(itsuki 必须知道,不告诉 = 失职)
4. 推荐理由(给 itsuki 论证逻辑可追溯)
5. 最终判断(诚实版)

3 个真坑:
- **坑 1**:ST25DV16K 没官方 Python 库 — 要么自写 I²C 寄存器读写,要么 port Arduino C++,1-2 周学习成本
- **坑 2**:PN532 在 Pi 上 I²C 不稳定 — 推荐切 SPI 模式
- **坑 3**:Pi 3A+ 只有 1 个 USB 口 — 部署后只能 SSH

### itsuki 原话 ⭐ 必填

(没有反驳,直接接受了详细分析,然后转向下个话题"点呼机的设计和代码应该放在哪里")

### 关键判断 / 学到的东西

CC 在这一段做的关键决定:**主动暴露坑,不修饰**。如果 CC 只说"全部 OK 可以下单",itsuki 部署时撞墙才发现 ST25DV16K 没 Python 库,会损失 2 周。

模式 6 取舍三角 — 每个配件的备选方案 + 决定性判断标准 + 最终选择都列出:
- Pi 3A+ vs Pi 4B / Pi Zero / Orange Pi / 二手 Pi 3B / ESP32(5 选项,各自缺点)
- PN532 V3 模块 vs PN532 NFC HAT(模块版省 60% 价 + 排针式更灵活)
- USB 小音响 + 3.5mm 直连 vs USB 声卡 vs 蓝牙音箱

### AC 价值 ⭐ 必填

- **对应核心问题**:#2 技術判断 + #3 問題解決
- **展示了什么**:
  - 不是"AI 推荐 itsuki 买",是 **itsuki 用 AI 做了完整的取舍三角分析,然后下单**
  - 11 配件每个都对应明确角色 + 选型理由 — 下次面试官问"为什么用 Pi 3A+ 不用 4B"itsuki 能答上来
