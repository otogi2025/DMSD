## §5.4 (d) 指导履历 → **C 案 — 默认不显示 + 学生可申请开示**

### 真问题不是"显不显示",是"这功能本身要不要做"

itsuki 卡在前面 — 看到老师 LINE 提"指导履历"+"事案录入"立刻警觉:**"如果有指导履历这个功能,这个系统就脱离宿舍管理范畴了,变成整个学校的管理系统了"**。

CC 第一次回答跑偏了 — 直接进 "学生看不看" 拍板,没回应 itsuki 的真问题。被 itsuki 纠正后回到正轨。

事实查证(老师 LINE 完整原文里搜):
- 「**生徒の指導歴入力**」 — 教师输入指导履历(寮務部教師確認用 段下)
- 「**生徒個人データ表示(... 指導履歴 ...)**」 — 个人数据字段含指导履历

→ **是的,老师明确要了 2 处**。但语境是"寮務部教师"(负责宿舍事务的教师组),指导内容范围 = 宿舍生活相关(违反宿舍规则、生活态度、点呼态度、同寮生纠纷等),**不是**学校全体老师对学业的全方位指导。

→ 仍在宿舍管理范畴内,但确实从"点呼+出寮届自动化"扩展到"含学生宿舍生活行为记录的综合宿舍管理系统"。

### itsuki 接受了"指导履历功能要做"+ 拍板 C 案

C 案 = 默认不直接显示 + 学生可"申请开示"按钮 + 老师决定(全部/拒绝/部分开示)。

理由(CC 提案 + itsuki 接受):
1. 跟日本学校"开示请求"惯例一致(默认 confidential / 申请就开示)
2. 老师写指导记录时不必担心学生当场看到 → 能直率写,有引继价值
3. 学生有"申请权"的存在感(透明性的弱保障)
4. 个人情報保護法的"开示请求权"自然走这个路径,完全合规

- §7.10 学生个人数据显示 — 指导履历行 △→❌(默认)+ 加 3 行(申请 / 老师决定 / 决定后阅览)

## §5.5 (e) 寮監账号 → **关闭 + 2 条新规则**

### 规则 2: 寮監账号管理 — 前台不允许自助注册

**潜在风险点**(我提了,itsuki 没改):
- 任何寮監能加新寮監 → 离职寮監若失信任前未及时禁用,可能加恶意账号

- "权威源"必须是「物理事实 / 官方书面文件」，不是「转述 / 摘要 / 简略 chat 消息」

CC（任何 LLM）不会主动质疑信息源（接到「老师说 X」就当 X 是事实）。**人侧（itsuki）必须做信息源审计** — 这是 AI 协作里「人不可被替代」的核心环节。

# §8 #AC候选 ⭐⭐⭐ Apple 个人开发者会员注册 — 让 DMSD 真正上架

> 对应 AC 核心问题: **#1 为什么做 DMSD（投入决心）** + **#3 怎么解决的（上架渠道这个非技术障碍）** + **#5 志望動機（"做真正能用的东西"的态度）**

## §8.1 事实

- itsuki 注册了 **Apple Developer Program**（苹果开发者计划），**个人名义**（不是学校 / 组织名义）
- 年费 USD $99（约 ¥15,000 / 年）— 自己出
- 目的: 让 Tomoshibi（学生 iOS App）真正**上架 App Store**，宿舍学生能搜索 / 下载 / 安装

## §8.2 为什么这件事值得记 AC

### (1) 这是「demo 项目」和「真正落地的产品」的分水岭

很多高中生项目止步于:
- GitHub 上有源码
- 自己手机能跑
- 老师面前 demo 一次

itsuki 这一步跨出去 = 决定让这个 app **真的进入 App Store 流通渠道** → 学生不需要 itsuki 在场也能装上 → 学校换届了系统照样能用 → 项目脱离"作者本人"独立存在。

这个跃迁在工程上要解决的事:

- 持续维护（年费续 / 系统升级配合 iOS 新版本）
- 用户支持渠道（联系邮箱 / FAQ / 反馈处理）

→ 不只是写代码，是**做一个真的产品**。

### (2) 个人名义 vs 学校组织名义 — 选择本身就是 AC 素材

苹果开发者账号有 2 种:
- **Individual / Sole Proprietor**（个人 / 个体经营者）— $99/年，自己名字
- **Organization**（组织 / 法人）— $99/年，需要 D-U-N-S 番号 + 法人确认

itsuki 选**个人名义**的含义:
- 这个项目**法律上属于 itsuki 自己**，不是宿舍 / 学校的资产
- 学校换届、寮監换人、itsuki 毕业后都不影响 app 归属
- 同时 = itsuki 个人承担合规责任（隐私政策署名 / 反馈联络人 = itsuki 本人）

→ 高中生主动以个人身份承担一个学校系统的法律责任 = **责任意识 + 长期承担姿态**

### (3) 自掏年费 $99 — 沉没投入

¥15,000 对高三学生不是小数目。这个**金钱承诺**让项目变成"我已经投入了，必须做完"的状态。

面试官会理解: 不是"试试看做点东西"，是"已经花了钱，所以这件事我必须负责到底"。
