## §8 リクエスト曲 投诉系统拍板 ⭐⭐ #AC候选

### 背景
4-30 後續 itsuki 追问音乐功能 — 5-01 拍板**赞/反対 → 投诉系统**改造。理由（itsuki 自述）:
> 「いいね / よくないねでは健全な空気を作れない。投稿者を傷つけずにダメな曲を排除したい」

把"对赞/反对"竞争模型改成"通报+先生介入"信任模型 → 学生匿名性 + 老师裁量权双保留。

### 拍板规则（spec → system_features.md §7.11.2）

| 累積通報数 | 措置 |
|---|---|
| 5 件 | 1 ヶ月 投稿禁止 |
| 解除後 さらに 5 件 | 3 ヶ月 投稿禁止 |
| さらに 5 件 | **永久** 投稿禁止 |

- 通报 7 件以上 → **老师 Web 看到「⚠ 通報多数」badge**（学生侧不显示，避免吊し上げ）
- 老师可手动封禁
- 通報理由: うるさい / 曲調が好みでない / 歌詞が不適切 / その他（自由文）

### iOS 实装
- AppStore: `songReportCounts` / `myReportTotal` / `songBanLevel` / `songBanUntil` / `canPostSong` / `reportSong(...)` 自动 escalate
- `SongReportReason` enum
- `SheetKind.songReport(songId:)` + 新建 `SongReportSheet`（4 radio + その他自由文）
- `MusicView` 改造：投稿順排序（id 倒序、不再赞/反対 ranking）+ hint banner「気になる曲があれば、通報ボタンから先生にお伝えできます。」+ 各 row 加「⚠ 通報」button
- `MusicDetailView`: 砍 賛成/反対 voting → 大「この曲を通報する」button
- `MusicNewView`: 封禁中显示红色 banner（「現在投稿停止中（M月D日 まで）」）+ 提交 button disabled

### AC 价值
- ⭐⭐ 産品設計 — "竞争 → 信任" 心理模型转变
- 学生匿名性（不公开通报次数）+ 自动 escalate（老师不必每次决策）+ 老师 override（超规则的特殊判断）三层保险
- 「永久禁投稿」最终大棒，但有 3 步缓冲（5 / 10 / 15）— 大部分恶搞会在 1 ヶ月停止前停手
