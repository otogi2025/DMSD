2. **约束变化方案要跟着变** — 5-06 决定不用 cloud agent → 原方案变成累赘 → 退役
3. **试错周期短 = 工程素养** — 13 天发现 + 退役 = 不固守原决策，能快速识别「方案对约束变化的脆弱性」

**对应 AC 核心问题**：
- #3（怎么解决的）：识别约束 → 设计方案 → 实战验证 → 约束变化时退役 — 完整工程闭环
- #4（学到了什么）：「沉没成本不应阻碍方案重选」+ 「设计 vs 约束」的依存关系
