## §16:15 Pi 3B vs Pi 3A+ 选型对比 — Amazon 日本 ¥6480 Pi 3A+ 拍板 #AC候选🌟

**路径**：itsuki 看淘宝套餐 Pi 3B ¥280 → CC 推荐评估 → itsuki 转查 Amazon 日本 → 发现 Pi 3B（¥8480）和 Pi 3A+（¥6480）并列 → 问两者区别。

**Pi 3B vs Pi 3A+ 核心差别**：

| 项 | Pi 3B | **Pi 3A+** |
|---|---|---|
| 价格（日本 Amazon）| ¥8480 | **¥6480**（省 ¥2000）|
| RAM | 1GB | **512MB** |
| USB 端口 | 4 个 | **1 个** |
| 以太网口 | 有 | **没有** |
| WiFi | 单频 2.4GHz | **双频 2.4 + 5GHz** ✨ |
| 尺寸 | 85×56 mm | **65×56 mm** |
| 3.5mm 音频 | ✅ | ✅ |

**为什么 3A+ 对 DMSD 更合适（反直觉结论）**：

1. **USB 不需要多个**：PN532 NFC 读卡器 + ST25DV 都是 I²C 接口（接 GPIO），不占 USB。点呼机 headless 部署（SSH 登录），不插鼠标键盘。1 个 USB 足够。
2. **以太网不需要**：宿舍用 WiFi，不会给点呼机布网线。
3. **WiFi 反而更强**：3A+ 双频，3B 单频 2.4GHz。点呼机数据量极小（一次签到 ≈ 1KB），实际用途感知不到差别，但 3A+ 在这点上"降维胜出"。
4. **3.5mm 音频口保留**：Pi Zero 2 W 没有 3.5mm 口要外接 USB 音频卡（零基础挑战）。3A+ 直接接小喇叭就能播放语音反馈。

**唯一硬约束**：512MB RAM。
- Raspbian Lite + Python + pyttsx3 TTS + NFC 驱动 ≈ 330MB
- 剩 ~180MB 余量（"紧但够"）
- 未来如果加人脸识别 / 视频流会不够，但 v1.0 范围内不做

**拍板**：**Pi 3A+ Amazon 日本 ¥6480**（一套含本体 + 另买电源 + SD 卡 + 外壳 ≈ ¥9500 日元 ≈ ¥480 RMB）。

### AC 素材（#3 問題解決 + #4 自己認識）

**标题候选**："为什么点呼机选 Pi 3A+（最便宜不等于最合适）"

**叙事链**：
1. 4-20 CC 推 Pi 4B 2GB（¥300 估价 → 实际 ¥500 太贵）
2. itsuki 质疑价格 → 回炉
3. CC 列 5 个替代方案 + 诚实标注 ESP32 = 大坑
4. itsuki 具体查 Amazon 日本，发现 Pi 3A+ 这个"冷门型号"
5. 深入对比后发现 Pi 3A+ 反而最合适（USB/以太网都用不到 + WiFi 更强 + 价格最低）
6. **工程启发**："最新 / 最强大"≠"最合适"；按真实需求（thin client）选而不是按 spec sheet 选

**可讲点**：
- 质疑 AI 的早期建议（CC 默认推 Pi 4B 4GB → 4-15 itsuki 砍到 2GB → 4-21 再砍到 3A+，**两次主动下压过度配置**）
- 硬件选型的"量体裁衣"思路
- 对 thin client 原则的贯彻（需求轻 → 硬件轻）

## §16:30 MVP 思维拍板 — 先 1 台 demo，验证后扩 4 台 #AC候选🌟

**itsuki 原话**："我决定先下单一台，用来做 demo，展示给老师看全流程。"

**决策内容**：
- 不一次性买 4 台点呼机（原计划 4-20 议题 A）
- Demo 阶段（4-28 前）：**1 台** Pi 3A+ + 1 个 PN532 + 1 片 ST25DV16K + 10 张 NTAG215 卡 ≈ ¥440 RMB ≈ ¥8800 日元
- 部署扩容阶段（管理员同意采纳系统后 + 批量淘宝采购 3 台）≈ ¥1000 RMB

**为什么是好决策**：

1. **降风险**：万一买回来架构有问题，损失 1/4（¥440 vs ¥1440）
2. **省钱**：Demo 阶段只为验证，不需要 4 台冗余
3. **AC 叙事强**：MVP 思维是通用工程方法论，可以直接讲
4. **技术上无损**：点呼机软件写一次，烧 4 份 SD 卡即可部署；先 1 台不是技术阻塞

### AC 素材（#3 問題解決 + #4 自己認識）

**标题候选**："MVP 思维 — 为什么先买 1 台而不是 4 台"

**叙事链**：
1. 原计划一次买 4 台（4-20 采购清单 ¥1200 RMB）
2. itsuki 意识到"没验证就批量采购 = 放大风险"
3. 重新切分阶段：Demo（1 台验证）→ 部署（3 台扩容）
4. **关键洞察**："产品还没被用户认可前，不要投入部署级资金"

**可讲点**：
- 工程"先验证再规模化"的原则
- 资金决策的阶段化（AC 考官：18 岁能主动控制预算风险是成熟信号）
- 对自己零基础的清醒认知（"如果第 1 台就踩坑，有机会调整 → 如果 4 台同时踩坑，进退两难"）

## §16:40 Amazon 商品甄别 — SunFounder 学习套件 ≠ Starter Kit

**触发**：itsuki 看到 SunFounder 套件（¥7218）问"这个没包括本体吧"。

**正确识别**：
- 标题 "Raspberry Pi **用的**入门电子工作套件" — 日语"用"= "给...使用" = 配件（不含主板）
- 支持列表列了一堆型号（Pi 5/4B/3B+/3B/400/3A+/2B/1B+/1A+/Zero W/Zero C）= 搭配"你自己已有的 Pi"
- 图里全是 LED / 电阻 / 面包板 / LCD / 传感器等学习元件，**没看到 Pi 主板本身**
- 没 SD 卡 / 电源 / 外壳（启动 Pi 必需的三样都没有）

**对 DMSD 价值判断**：¥7218 里 80% 元件（LCD / 步进电机 / 按键矩阵 / 各种传感器）DMSD 用不到，性价比低。DMSD 只需要 PN532 + ST25DV16K + 几根杜邦线 + 可选 LED/蜂鸣器。

**正确搜索关键词**（给 itsuki）：
- `"Raspberry Pi 3 Model A+ スターターキット"`（日语：入门套装 = 含本体 + 启动必需）
- `"Raspberry Pi 3 A+ セット 本体"`
- 或者分开买：Pi 3A+ 本体 ¥6480 + 电源 ¥1200 + SD 卡 ¥800 + 外壳 ¥1000 ≈ ¥9500 日元

**AC 小素材**：采购甄别能力（看商品描述里的"用"、"支持列表"、图片元件判断是否含主板），这类能力在工程项目里常被忽视但实际每天用到。
