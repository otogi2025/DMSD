## C. backend 单点系统级 P0 ⭐ — 4 个上架阻塞 / 部署阻塞

不跨端的 backend 单点 P0：

### C-1. `rollcall.py:83-86` minute-5 整点 ValueError
```python
window_minus5 = session.scheduled_window_start_at.replace(
    minute=session.scheduled_window_start_at.minute - 5
)
```
22:00 session（seed.py:207 真建）→ minute=-5 → ValueError。第二行 `replace(minute=max(0, -5))` 是死代码（外层先炸）。

**修复**：用 `timedelta(minutes=5)`。

### C-2. `applications.py:151+254` route shadow
`@router.get("/{application_id}")` 在 151 行注册早于 `@router.get("/pending-for-me")` 254 行 → FastAPI 顺序匹配 → `/pending-for-me` 永远被 UUID 动态路由抓 → UUID("pending-for-me") 失败返回 422 → 老师 Web 待审申请列表 100% 打不开。

**修复**：把 pending-for-me 提前注册。

### C-3. `alembic/env.py:65-69` 不读 DATABASE_URL
直接从 alembic.ini 读死 SQLite URL（`sqlalchemy.url = sqlite:///./tomoshibi_dev.db`）→ VPS Postgres 部署跑 `alembic upgrade head` 永远更新错 DB（本机 SQLite 文件）→ prod schema 永远不更新。

**修复**：`env.py` 加 `config.set_main_option("sqlalchemy.url", get_settings().database_url)`。

### C-4. `accounts.py` 缺 DELETE /accounts/me
BACKEND_DESIGN_LOG §5.1.6 已 spec / README 自承 "待续" / Apple 5.1.1(v) 自 2022-06 起强制要求 in-app 删账号 → 无实装 = 上架直接 reject。

**修复**：accounts.py 加 delete_my_account + Student.status enum 加 'deleted'（已在 5-07 拍板）+ alembic migration + AuditLog 记录。
