### B.4 [18:15] [debug 元规则 — bash 3.2 heredoc bug 定位]

**现象**：全局 hook 触发后中文乱码：
```
itsuki 当前消息含「��— 收尾关键词。
当前项目：**Tango**（cwd: ��
```

**第一假设**：locale 不是 UTF-8 → 在 hook 顶部 `export LANG=en_US.UTF-8` → **跑测试还乱**。

**第二假设**：bash heredoc 在紧贴右全角标点（」/）/】）时把变量末字节 + 全角字符首字节合并解析 → 测试 5 种写法验证：
```
紧贴全角引号: 「��末尾        ← 崩
加空格: 「 收尾 」末尾          ← OK
半角方括号: [收尾]末尾          ← OK
```

**修法**：所有 `「$VAR」` 改成 `[$VAR]`（半角方括号）。

**归属候选**：itsuki 拍板「修」后我自己 debug。两个假设都自己测试验证，没乱猜。

**AC 价值** ⭐⭐⭐⭐⭐：
- 模式 2 × 2（locale 假设崩 / 紧贴标点假设验证 ✅）
- debug 元规则：假设崩 → 不固执，**换另一个假设**
- 工程纪律：先写最小测试用例验证根因，再改 production 代码
