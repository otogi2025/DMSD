# Android 对齐 iOS — 视觉签收清单（itsuki 模拟器逐屏肉眼核对用）

> **为什么有这份清单**：源码层对齐（界面有没有 / 文字对不对 / 颜色令牌 / 字号）CC 已全验过 + 编译退出码 0。但「画出来长得像不像 iOS」（真实像素、字体渲染、间距观感）只能人开模拟器肉眼看。CC 无图形界面跑不了模拟器，所以把每屏要核对的点列成清单，你照着逐屏打勾，快且不漏屏。
>
> **怎么用**：
> 1. Android Studio 开模拟器跑 Android app；旁边 iPhone 模拟器 / 真机跑 iOS app 对照。
> 2. 按下表逐屏：进对应路由 → 核对三件事 ——
>    - **文案**：表里「关键日语文案」在屏上有没有、一字不差不（不该出现中文）。
>    - **布局**：整体结构、卡片顺序、按钮位置像不像 iOS 对应界面。
>    - **配色**：主色（青）/ 警告（橙）/ 危险（红）/ 成功（绿）观感跟 iOS 一致不。
> 3. 每屏 OK 就打 ☑；有偏差记在「备注」列，回头丢给 CC 修。
>
> **已知可接受差异**（不算偏差，别记）：
> - 字体：Android 用系统 Sans + 等宽，iOS 用 SF / Noto，渲染必然略不同（视觉差可接受，[[差异矩阵]] 已定）。
> - 玻璃拟态：iOS 用 LiquidGlass 真玻璃，Android 用 ModalBottomSheet 半透明降级（已定方案）。
> - 演示数据内容：两端 mock 的具体值（人名 / 日期 / 目的地）不同没关系，看的是格式 / 标签 / 布局。
