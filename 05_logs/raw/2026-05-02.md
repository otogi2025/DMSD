### #AC候选 ⭐⭐ JWT Keychain vs UserDefaults — CC 主动诊断 unknown unknown

**金句**（CC 主动告诉 itsuki）：「**UserDefaults 是明文 plist、越狱机能直接读、JWT 这种机密放进去不安全。业界标准是放 Keychain**」

**背景**：iOS 网络层建设到 commit 3（KeychainService）时，CC 按 §对话规则 §7 主动诊断告诉 itsuki：
- itsuki 不知道：UserDefaults 是明文存储
- itsuki 不知道：JWT token 这种 credential 跟普通 user data 应该分级保护
- itsuki 不知道：iOS 系统自带 Keychain 这种硬件加密的 secure storage
- itsuki 不知道：`kSecAttrAccessibleAfterFirstUnlock` 等访问控制 attribute

CC 给 itsuki 解释:
- 类比：UserDefaults = 你电脑桌面的 .txt 文件 / Keychain = 银行保险箱
- 越狱机能直接读 UserDefaults plist 文件
- Keychain 数据用硬件芯片加密、即使 backup 也加密
- 业界 iOS 应用（银行 / 邮箱 / 微信）的 token 全在 Keychain
