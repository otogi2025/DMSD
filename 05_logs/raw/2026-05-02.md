## §1 起手 + 既存规则盘点

itsuki 提问：「claude.md 里有没有提到我需要 claude 辅助我学习、提醒我，因为我是小白有很多事不了解，也有很多做法我自己认为正确但实际上是错误或者效率低效。有些时候我的视角没有打开没有意识到有更多做法」。

她举的真实例子：「在 ai 告诉我之前我都不知道这么储存项目文件，不知道 git 之类的。是 ai 在我没有任何要求的情况下主动提出来的」。

CC 盘点既存规则：

| 来源 | 内容 |
|---|---|
| 全局 `~/.claude/CLAUDE.md` | "不假设任何先验知识" / "做'教练'不只是'执行者'" |
| 项目 `CLAUDE.md §对话规则 §2` | "主动告诉 itsuki 不知道但应该知道的概念" |
| memory `MEMORY.md` | "Aggressively surface unknown unknowns" |

→ **结论**：现有规则覆盖**概念扫盲**（你不知道什么是 X → 解释 X），但**没明确写做法诊断**（你已经在做某事但做法不优 → 主动指出更优做法）。两者方向不同。

→ CC 提议在 §对话规则 加一条 §7。itsuki：「加强这部分。在这之前你有什么想从我这里知道的，问我」。

## §4 AC 候选

**核心金句 ⭐**：「提醒我学习扩展我的思维这个很重要」

itsuki 对 AI 协作的**核心期待**：不只是执行，而是**打开她看不到的视角**。

她说自己是"小白"不是自卑话术，而是清醒的自我认识 — 原话「我自以为正确但实际上是错误或者低效」「我的视角没有打开没有意识到有更多做法」「不知道自己不知道什么」。这种**自我觉察 + 主动要求 AI 挑战自己**对零基础学生是非常少见的**元认知**（meta-cognition / 自分の認知を認知する力）。

→ 可写进 AC 自我推荐书的「AI 与の協働姿勢」段落：「私は AI を、コードを書いてくれるツールではなく、**私の視野を広げてくれる副操縦士**として使っている。自分が"知らないことを知らない"領域こそ、AI が能動的に開いてくれる」。

→ 可写进面试问题 #4「学到了什么？」：项目过程中很多关键转折是 AI 主动提的（Git / 项目分文件 / AC 留截图证据），我学到的不是某个具体技能，而是**"主动让协作者挑战自己的视角"这个习惯**。
