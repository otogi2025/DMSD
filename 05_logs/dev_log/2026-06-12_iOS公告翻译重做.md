## bug / 坑（值得记）

- **Swift 6 完全并发「sending session」编译错**：`translationTask` 闭包里 `await session.translate(text)`，项目开 `-swift-version 6`，报「sending main actor-isolated 'session' to nonisolated method translate」。
- 排查：试 3 方案均失败（①回调闭包改 @Binding ②局部 let 解耦 self ③`sending` 参数转移 session）→ 连查 4 处 Apple SDK swiftinterface 定位真因：`translationTask` action 是 nonisolated 非 @Sendable / `translate` nonisolated / `TranslationSession` 非 Sendable / `Binding` 非 Sendable。**真因 = 闭包定义在 @MainActor View body 默认继承 MainActor 隔离 + session 非 Sendable 不能跨 actor。**
- 解决：`@preconcurrency import Translation`（框架并发标注未跟上 Swift6 时的官方过渡手段），双 scheme 立刻过。并清理掉中途引入的多余 `translateBody` 中转函数（技术债）。
