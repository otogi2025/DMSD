## 0. 开工前先读这段

### 三条保命规则

1. **接线、拔线前一律先拔掉 Pi 的电源。** 带电插拔可能把板子烧了。
2. **每次只接一个模块，接完立刻验收，过了再接下一个。** 一次全接上，出问题你分不清是哪根线的锅。
3. **红线（正极）绝对不能插反。** 尤其风扇那个 2 针接头，插反可能烧。

### 顺序为什么是这个顺序

本文的模块顺序是 **LED → PN532 读卡器 → ST25DV 贴纸 → 风扇喇叭**。

注意这跟 `../点呼机接线说明.md §7` 写的顺序（PN532 先）**不一样，是有意改的**：LED 不需要焊接、接错了也烧不了东西、亮不亮一眼就知道。拿它当第一个模块，你能在零风险的情况下先把三个基本功练出来 —— 数针脚、认长短腿、验证「代码真的能控制硬件」。这三样练熟了再去碰要焊接的 PN532，成功率高得多。

### 总时间预估

不含等快递和翻车重来：**软件段约 1-2 小时**，**焊接段第一次约 2-3 小时**（含练习），**接线验收段约 2 小时**。别想一天干完，分两三天，每天推进一个阶段。

## 阶段 1 — 清点包裹（不碰工具，30 分钟）

对照 `../点呼机采购清单.html` 的「④ 采购清单」表格，把三家（秋月電子 / Switch Science / Amazon）的箱子拆开逐项打勾。

**重点确认这几样，缺了后面会卡死**：

| 东西 | 为什么关键 |
|---|---|
| Pi 3A+ 主板 + 5V3A 电源 | 缺一个就什么都干不了 |
| microSD 卡 + 读卡器 | 系统烧在这上面；你自己原有的，别忘了找出来 |
| 4 色 LED（红/绿/蓝/白）+ 220Ω 电阻 | 阶段 4 要用 |
| 10kΩ 电阻 | ST25DV 的门铃线要用，只买了这一种阻值别跟 220Ω 搞混（看色环或直接用万用表量） |
| 烙铁套装 | 阶段 3 焊接 |
| 万用表 MAS830L | 全程排查靠它 |
| 面包板 + 杜邦线 | 阶段 4 免焊试接 |
| PN532 V3 套件 / ST25DV ×4 / NTAG215 白卡 | 三个 NFC 主角 |

**验收**：清单上每一项都在手上，或者明确知道缺哪个、什么时候到。

**顺便做**：把 PN532 和 ST25DV 两块板子拿出来，用手机拍张**正反面清晰照片**，把板子上印的字（丝印）拍清楚。后面接线要靠这些字认脚，而且实物跟文档可能有出入 —— 以实物为准。

## 阶段 2 — 软件先跑通，一根线都不接（1-2 小时）

**为什么先做软件**：这样等你开始接线以后再出问题，就能确定「一定是硬件的锅」，排查范围小一半。反过来先接线，出了问题你要同时怀疑软件和硬件两边。

### 2.1 烧系统卡 + SSH 连上

照 `部署SOP.md §1` 做。做完你应该能在 Mac 终端敲 `ssh rollcall-1@rollcall-1.local` 登进去
（`@` 前面是烧卡时填的用户名，`@` 后面是烧卡时填的主机名，两个恰好都叫 rollcall-1）。

**验收**：终端提示符变成 `rollcall-1@rollcall-1:~ $`，说明你已经在树莓派里了。

**卡住了**：连不上先查路由器管理页面里有没有出现这台设备 —— 有 = Wi-Fi 密码对、SSH 有问题；没有 = Wi-Fi 名或密码填错了，重烧卡。

### 2.2 开 SPI / I²C 开关

照 `部署SOP.md §2` 做。这是两种芯片间通信方式的开关，树莓派默认是关的，不开后面读卡器和贴纸都不认。

**验收**：`ls /dev/spidev*` 有输出、`ls /dev/i2c-*` 有输出。

### 2.3 装代码 + 依赖

照 `部署SOP.md §3` 做。

**验收**：`.venv/bin/python -m src.main --help` 打出参数说明，不报错。

> ⚠️ 记住是 `python -m src.main`，不是 `python src/main.py` —— 后者会报 `ImportError`。这是 Python 包的运行方式，不是代码有 bug。

### 2.4 空跑模拟模式

```bash
.venv/bin/python -m src.main --config config/config.json --simulate
```

这个模式下没有真硬件，你用键盘打字假装刷卡（用法见 `部署SOP.md §5`）。

**验收**：能打 `card 04a1b2c3d4e5f6` 有反应、打 `quit` 能干净退出。此时后端还没配好，报网络错是正常的 —— 你要看的是**程序本身跑起来了、状态机在转**。

**到这里的意义**：软件这层已经证明没问题。后面所有故障都可以先怀疑硬件。

## 阶段 3 — 焊接（第一次约 2-3 小时）

这是你整个项目**第一次拿烙铁**，也是全程最容易劝退的一步。分成练习和实战两段，别跳练习。

### 3.1 先搞懂要焊什么

- **PN532**：套件自带排针，要把排针焊到板子边缘的一排孔上（焊完才能插杜邦线）
- **ST25DV**：板底 6 个焊孔，焊 6 根排针

排针 = 一小排金属针，焊上去以后模块才能用杜邦线连到树莓派。**焊接本质上就是用熔化的锡把金属针和板子上的金属圈粘在一起，让电能通过。**

### 3.2 练习（别省这一步）

排针套装买的是 60 个，绰绰有余。**先在废排针 + 面包板上练 10 个焊点**，练到你能稳定做出「锥形小山、表面光亮」的焊点再动真板子。

烙铁调到 **约 350℃**（套装是可调温的）。基本动作：

1. 烙铁头先同时碰**针**和**板子上的金属圈**，加热约 2 秒
2. 焊锡丝送到**接缝处**（不是送到烙铁头上），锡会自己流进去
3. 先撤锡丝，再撤烙铁
4. 不要吹，让它自然冷 2 秒（吹会形成裂纹）

**焊点好坏对照**：

| 样子 | 判断 |
|---|---|
| 光亮、锥形、包住针脚 | ✅ 好 |
| 灰暗、粗糙、像磨砂 | ❌ 冷焊（温度不够或动了），要重焊 |
| 圆球状、跟板子之间有明显缝 | ❌ 没粘上板子，虚焊，重焊 |
| 两个针之间连成一片 | ❌ 短路，用吸锡器吸掉重来 |

### 3.3 正式焊 + 立刻验收

焊完每块板，**用万用表验收，别靠肉眼**：

万用表拨到**通断档**（有蜂鸣器图标那档），两支表笔分别碰两个点，**通了会响**。

1. **每个焊点单独测通**：一支表笔碰针尖、另一支碰板子上该针对应的走线/焊盘 → 应该**响**。不响 = 虚焊，重焊。
2. **相邻针之间测不通**：两支表笔碰相邻两根针 → 应该**不响**。响了 = 短路，吸锡重来。

**验收**：所有针「对自己通、对邻居不通」。这一步不过关就往下走，后面会出各种莫名其妙的读不到卡，且极难排查。

## 阶段 4 — 逐个模块接线 + 逐个验收（约 2 小时）

**每接一个模块之前先拔电源，接完再上电。**

### 4.1 LED ×4（最简单，练基本功）

接法查 `../点呼机接线说明.md §4`。要点复述两个最容易错的：

- **长腿（正极）→ 串 220Ω 电阻 → 5V 针**；**短腿（负极）→ GPIO 信号针**
- **低电平 = 亮**（跟直觉相反，这是接法决定的，代码里已经处理好了）

**验收**：跑起主程序，启动瞬间应该亮**白灯**（启动中），进待机后变**蓝灯**。

**卡住了**：
- 完全不亮 → 十有八九长短腿接反了（LED 有方向性），拔下来调头
- 4 个都不亮 → 先用万用表量 5V 针和 GND 针之间有没有 5V

### 4.2 PN532 读卡器（路径 A：刷学生卡）

接法查 `../点呼机接线说明.md §2`。

⚠️ **最容易踩的坑**：PN532 V3 板子上有**拨码开关或跳线**，出厂默认可能是 I²C 模式，**必须先切到 SPI 模式**。到货看它自带说明书或板上丝印。这一步不做，接线全对也读不到卡。

**验收**：拿套件里自带的测试卡或 NTAG215 白卡贴上去，日志里应该打出一串卡号（14 位十六进制）。

**卡住了**：查 `部署SOP.md §7` 的故障对照表「PN532 读卡无反应」那行。

### 4.3 ST25DV 贴纸（路径 B：手机碰）

接法查 `../点呼机接线说明.md §3`。这个模块比 PN532 多一根 **GPO 门铃线** —— 手机把数据写进贴纸后，靠这根线通知树莓派「有新东西了，快来读」。

⚠️ **这根门铃线要串一个 10kΩ 电阻上拉到 3.3V**（别用 220Ω，阻值不对不管用）。

**验收分两步**：
1. **先测认得到芯片**：`i2cdetect -y 1` 应该看到 `0x53` 和 `0x57` 两个地址。看不到 = 接线或焊点问题，回阶段 3 复查。
2. **再测手机能写进去**：用你的 iPhone 打开 Tomoshibi App 点签到，贴上去。日志应该打出解析到的学生 UUID。

**卡住了**：这是全项目**代码里标了最多「待硬件联调核实」的地方** —— ST25DV 的寄存器位号、GPO 引脚号都是照芯片说明书写的、没实物验证过。这一步出问题**不一定是你接错了，可能真是代码要调**。到时候把日志贴给我，我对着芯片手册查。

### 4.4 风扇 + 喇叭

接法查 `../点呼机接线说明.md §5 / §6`。

⚠️ **风扇绝对不能接 GPIO 信号针**（信号针最大 16mA，风扇要 100mA，会烧板子）。只接 5V 针和 GND 针。

**喇叭验收**：装完系统要用 `raspi-config` 把声音从 HDMI 切到模拟 3.5mm，否则不出声（这不是坏了）。切完刷一张已绑定的卡，应该播日语姓名。

## 卡住了怎么办

1. **先查** `部署SOP.md §7` 的故障对照表 —— 常见 8 种现象都在里面
2. **再查** 本文各阶段的「卡住了」小段
3. **都没有** → 把三样东西拿来问我：① 现象（灯什么颜色 / 有没有声音）② 日志（`journalctl -u tomoshibi-rollcall -n 50`）③ 你上一步动了什么

**别做的事**：一次改好几个地方再上电测。改一处、测一次，否则你不知道是哪个改动起的作用。
